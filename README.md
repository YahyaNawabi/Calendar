# 📅 Calendar App

A minimalistic calendar web app that displays the current date, day, month, and year using HTML, CSS, and JavaScript. The design is clean and easy to navigate, offering a modern look.

## 🚀 Features
- Shows the current date, day of the week, month, and year
- Simple and visually appealing design
- Built with pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
